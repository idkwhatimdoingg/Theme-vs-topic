Theme vs Topic - ELA lesson
This project is a simplified prototype of an AI-driven English Language Arts tutor.
It demonstrates how an adaptive system can evaluate student responses, apply
rule-based scoring, and generate targeted AI responses to guide learners toward mastery.

# Skill
Theme vs Topic (Grades 6–8)

## How it Works
- Prompts students to identify topic, then theme
- Scores responses on a 0–2 rubric
- Generates adaptive AI responses based on score
- Re-prompts students and tracks attempts to mastery

## What This Demonstrates
- Translation of pedagogy into system logic
- Adaptive decision-making without ML
- Readable, explainable AI behavior design
